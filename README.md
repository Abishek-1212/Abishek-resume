# Interactive Resume

## Overview

This project is a responsive and interactive resume website developed using **HTML, CSS, JavaScript, and jQuery**. It presents personal, academic, and professional information in a clean two-column layout with animated skill indicators and a modern user interface.

The resume is designed to showcase technical skills, education, internship experience, certifications, and contact information in an engaging and visually appealing format.

---

## Features

| Feature | Description |
|---------|-------------|
| Responsive Design | Optimized for desktop and mobile devices. |
| Modern UI | Clean two-column layout with a professional appearance. |
| Animated Skill Bars | Programming skills animate automatically on page load. |
| Circular Soft Skill Indicators | Animated circular progress indicators for soft skills. |
| Professional Profile | Displays education, internship experience, and personal summary. |
| Contact Information | Includes phone number, email, GitHub, and LinkedIn profile. |
| Social Media Links | Quick access to GitHub, LinkedIn, and Instagram. |
| Certifications | Displays certification links for online courses. |
| Smooth Animations | CSS transitions and jQuery animations enhance user experience. |
